# 01 — Project Brief

**Proyek:** CampusFolio (Campus Social Media & Portfolio)  
**Tim:** Team 3  
**Status:** Pertemuan 1 • 6 Oktober 2026 • Draft v0.1  

---

## Ringkasan Proyek

| Elemen | Keterangan |
| --- | --- |
| **Nama Proyek** | **CampusFolio** *(usulan tim)* |
| **Kasus Proyek** | Kasus 3 — Campus Social Media / Portfolio |
| **Masalah Utama** | Keahlian dan portofolio mahasiswa tersebar di banyak platform; sulit menemukan rekan proyek dengan skill/minat yang saling melengkapi; konten buatan pengguna membutuhkan moderasi agar lingkungan kampus tetap kondusif dan aman. |
| **Pengguna Utama** | Mahasiswa aktif yang ingin menampilkan keahlian dan mencari partner proyek/lomba. |
| **Pengguna Pendukung** | Admin / Moderator kampus atau organisasi mahasiswa yang mengawasi kepatuhan konten. |
| **Tujuan Produk** | Mahasiswa dapat menampilkan profil dan portofolio terpusat, menemukan kolaborator relevan dengan cepat melalui pencarian dan rekomendasi AI cerdas, serta berinteraksi secara aman. |
| **Data Awal** | Profil mahasiswa (nama, prodi, bio), daftar keahlian (skills), minat (interests), portofolio proyek, dan posting lowongan/mencari anggota. |
| **Scope MVP** | Modul autentikasi, manajemen profil & portofolio, feed posting, pencarian berbasis kata kunci/tag, prototipe AI rekomendasi rekan, dan antrean moderasi sederhana. |
| **Batasan Penting** | Rekomendasi AI hanyalah saran (bukan keputusan mutlak); moderasi konten sensitif wajib ditinjau oleh manusia (*human-in-the-loop*); kegagalan AI tidak boleh melumpuhkan fitur inti aplikasi. |
