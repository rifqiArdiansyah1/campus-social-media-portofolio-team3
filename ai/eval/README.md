# Direktori AI Evaluation & Datasets

Direktori ini digunakan untuk menyimpan dataset pengujian, benchmark, dan skrip evaluasi akurasi model AI:

- `eval-recommendation-dataset.json`: Koleksi data profil dummy (30–50 sampel) untuk menguji relevansi rekomendasi.
- `eval-moderation-dataset.json`: Koleksi kalimat postingan uji (bahasa Indonesia gaul, akademik, borderline) untuk mengukur precision dan recall filter moderasi.
