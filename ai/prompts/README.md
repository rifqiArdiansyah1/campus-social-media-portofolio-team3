# Direktori AI Prompts

Direktori ini digunakan untuk menyimpan seluruh template prompt sistem, few-shot examples, dan instruksi model generatif yang digunakan dalam aplikasi CampusFolio:

- `recommendation-prompt.md`: Prompt untuk model LLM pencocokan semantik dan pembentukan alasan komplementer.
- `moderation-prompt.md`: Prompt untuk klasifikasi teks dan penilaian potensi pelanggaran norma kampus.
